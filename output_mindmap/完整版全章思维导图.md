## 1. 计算机硬件

### 历年分值：0-3 分（低频）
### 五大部件
- 运算器 / 控制器 / 存储器 / 输入 / 输出
### CPU = 运算器 + 控制器
#### 运算器组成
- ALU（算术逻辑单元）
- AC（累加寄存器）
- DR（数据缓冲寄存器）
- PSW（状态条件寄存器）
#### 控制器组成
- IR（指令寄存器）/ PC（程序计数器）
- AR（地址寄存器）/ ID（指令译码器）

### 校验码
#### 码距
- 码距越大，检错纠错能力越强
#### 奇偶校验码
- 1 位校验位，检 1 位错，不可纠错
#### CRC 循环冗余校验码
- 检错不可纠错
- 模 2 除法 + 生成多项式
- 余数 = 0 无错

### 指令系统
#### 指令组成
- 操作码 + 操作数（地址码）
#### 寻址方式
- 立即/直接/间接/寄存器/基址/变址
#### CISC vs RISC
- CISC：复杂指令，微程序，可变长
- RISC：精简指令，硬布线，定长单周期
#### 流水线
- 取指 → 分析 → 执行
- 超流水线：细化分段+增加级数+提高主频

### 存储系统
- 寄存器 → Cache → 主存 → 外存
- 磁盘调度

### 输入/输出 & 总线
- 程序控制 / 中断 / DMA
- 内部/系统/外部总线

## 4. 嵌入式技术

### 历年分值：2-3 分（低频，超纲 50%）

#### 冯·诺依曼结构（普林斯顿结构）

- MCU / MPU / DSP / SOC

## 14. 软件可靠性基础

### 历年分值：2 分（低频）
### 基本概念
- 可靠性：规定条件+时间+完成规定功能的能力

### 软硬件可靠性区别
- 复杂性 / 物理退化（硬件才有）/ 唯一性 / 版本周期

### 定量指标
- 失效概率：0→1 递增
- 可靠度 = 1 - 失效概率
- MTTF（平均失效前时间）
- MTTR（平均恢复前时间）
- MTBF（平均故障间隔时间）= MTTF + MTTR
- 可用性 = MTTF / (MTTF + MTTR) × 100%

### 串并联系统可靠性
- 串联：R = R1×R2×...×Rn
- 并联：R = 1 - (1-R1)×(1-R2)×...×(1-Rn)

### 可靠性测试
- 定义运行剖面
- 设计测试用例
- 收集失效数据
- 建模评估

### 可靠性设计
- 容错技术（NVP/N版本/恢复块）
- 避错技术
- 冗余设计（硬件/软件/信息）
